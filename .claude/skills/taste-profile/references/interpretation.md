# 解释统计结果

- **只和全站比会误判**：全站二十年的标签里早年的东方、Fate 老图很多，人工标签和模型标签的习惯也不一样。比如"白发偏爱"，换成同时期、同模型的对照后可能就消失了。结论要以对照组为准：`looks.hair[].vs`、`camera`、`vsCn`。
- **中文圈只在同一尺度内比**：中文平台有审查，那边公开的图几乎没有较敏感以上。脚本已经只用全年龄 / 轻微去比外观和镜头。也不要把"中文圈画师画什么"说成"中国用户喜欢什么"，它是最接近的参照，但不等同。
- **按张数和按角色是两回事**：几个存了上千张的角色会主导张数比例，所以"按张数最爱的发色"不等于"按角色最爱的发色"。`hairByCharacter` 是每个角色只算一次的版本；`conv`（出现过的角色里存到 20 张以上的比例）能解释"为什么觉得自己存了很多某种发色"。
- **性格要扣掉人气**：按张数，"冷面寡言"可能排第一，但只是因为这类角色本来就火。看 `popularity.archetypes` 的 ratio 和区间（lo–hi）：区间整体大于 1 可支持“相对该对照收得更多”；结论仍受对照、样本与原型表覆盖范围影响。
  - 性格原型来自 `archetypes.json`，是人工对照表，只覆盖常见角色；用户的主力作品里有新角色时，可以先补进表里再算。
  - 不认识的角色不要编性格，只描述数据，比如"存的图里六成在笑"。
- 扣人气时不算男性角色（图里六成以上画了男性的角色），否则「跳过的」会被男性角色占满。
- **`popularity.hidden` / `skipped`** 往往最有意思：同一部作品里谁被超配、谁被跳过（例如同一部番里偏向另一支乐队）。描述时说清楚人气用的是 Danbooru 帖子数，偏日本和欧美。
- **有些数据会说"没有差别"，这本身就是结论**：几点存图、一轮连续存图里尺度变不变（`rhythm.hourNsfw`、`sessionPos`）。未观察到明确差异时，描述为“在这份样本中未发现明显差异”；不要据此断言口味稳定，更不能推断用户情绪。
- **`arcs`**：入坑到高峰的天数和高峰集中度。数据刚开始就在收的角色已经排除了，但时间太短的库看不出慢热还是快热。
- **`resave`**：隔很久又存了一次的同一张图，可能提示持续关注，也可能来自重复下载或备份。先核对来源与时间，不能仅凭重复保存断言吸引力或偏好更强。
- **样本量**：样本少的时期（几百张）、对照组每组约 700 张（只算女性角色后），结合有效样本量、区间、抽样方式及差异幅度评估；小差异通常不宜做强结论，不把固定百分点当作通用显著性阈值。

# pose-covers

按姿势找图的封面（PoseWear 线稿）放这里。Emaki 不带这些图，没有的姿势会按骨架画一个小人。

- 把 PoseWear 的线稿文件原样放进来，文件名不要改，例如 `full_single_P017_side.webp`、`upper80v2_P004_front.webp`，双人是 `pair60_P054_front.webp`。
- 直接平铺在这个文件夹里就行，放在 `t/`、`i/` 或者 `p/t/`、`p/i/` 下面也认（`i` 是大图）。
- 也可以在设置 → 姿势检索里「从 PoseWear 文件夹导入线稿」，会复制进数据目录。

这个文件夹里的图片不会提交到仓库。

# 中文词库来源

`danbooru-zh.json.gz` 由 `apps/server/scripts/build-zh-dict.ts` 从下面的数据集生成（精简了字段）：

- 数据集：ame-la/danbooru-tags-data-zh
  - Hugging Face：https://huggingface.co/datasets/ame-la/danbooru-tags-data-zh（修订 1b0900609723e8704c5b69329ed9fde65f5457d5）
  - GitHub：https://github.com/amenorira/danbooru-tags-data-zh（commit 5805e4700f52dbe66567b84a157e29a41b3a5bcc）
- 许可证：MIT（全文见下）
- 生成时间：2026-09-26T18:44:33.213Z
- 数据根据 Danbooru 公开的标签信息整理。

备选（未采用）：EhTagTranslation（CC BY-NC-SA 3.0，不能随本仓库分发）；byzod Tags-zh-full-pack（MIT，但数据陈旧）。

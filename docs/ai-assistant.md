# AI 助手（实验）

设置 → **AI 助手 · 实验**，默认关闭。此功能独立于本机 tagger 和实验性的 Qwen 图片分类，不下载或部署推理模型。

## 使用

助手可通过 MCP `import_images` 将已下载的本地图片复制到已有图库目录，保留原下载和旧版图片；先用 `read_library /api/library-roots` 选择目标。工具按文件内容查重、避开重名，返回可立即查询的图片 ID，随后可补来源、角色和画师并展示。缩略图、识别和查重复用现有任务链，无需额外全库扫描。HTTP 接口为 `POST /api/images/import`，参数 `{rootId, dir, files:[{path, fileName?}]}`；一次 1–20 个本地普通图片文件，每个最多 128 MiB。撤销仅将本次新增副本移到系统回收站，已存在的图片不受影响。

1. 打开开关，弹窗会列出开启后哪些内容会发出去、助手在本机能做什么，确认后才开启，并检测本机 Agent 应用。检测只检查安装、认证状态和模型列表，不发起推理，也不发送图库内容。
2. 在设置页选择 Agent 应用：
   - **Codex**：使用已有 Codex 安装和登录。自动检查 PATH 及 Windows Codex 桌面安装位置；也可指定可执行文件的绝对路径。Codex 的线程记录（消息、工具输出、模型回复）由 Codex 自己保存在 `CODEX_HOME`（默认 `~/.codex/sessions`），也会出现在 Codex 自己的历史列表里；删除或关闭 Emaki 数据不会清理这些记录，需要时在 Codex 里归档或删除。
   - **Pi**：随 Emaki 安装 `@earendil-works/pi-coding-agent`，填写模型 API 地址、协议、模型 ID 和密钥。支持 Chat Completions、Responses、Anthropic Messages。自定义模型的视觉和思考能力由配置声明；已有 Pi 模型的能力使用其模型目录。
   - **DSH**：复用本机 DeepSeek Harness 安装及模型登录，在常见 Windows 桌面安装目录和 PATH 自动查找，也可指定路径。通过 ACP 驱动 Emaki 自己的会话，模型、思考强度和看图能力从运行时读取。
3. 点右下角气泡，新建对话。气泡和面板标题栏均可拖动，位置记在本机浏览器；缩放窗口或展开面板时会保持在可见范围。模型和思考强度在输入框下方选择；Agent 应用在设置页切换。
4. 可以选中图库图片、打开一张图片，或直接提问。每条消息记录当时的页面和图片选择，图片由 agent 按需通过 MCP 读取。
5. 助手可返回图片卡片和表格。勾选卡片图片会更新输入框下方的上下文，再输入任意后续指令发送；“使用页面选择”可切回图库的选择。业务接口返回撤销令牌的修改可直接撤销。令牌遵循应用原有生命周期，重启后可能失效。

任务中断、出错或手动停止后，可点击“继续处理”或“重试并继续”。恢复沿用原请求的图片范围、会话历史与操作记录，助手先核对已完成部分，再继续剩余工作；也可直接输入新指令。短暂网络断线会自动重连，旁边提供“立即重连”入口。

连续工具记录默认折叠，展开后可查看详情和撤销；图片、表格结果卡片保持可见。未识别列表刷新成功后会清理已移出列表的选择，输入框上下文同步更新，已发送消息保留当时的选择快照。

设置 → AI 助手 → 操作权限可选择「按需审批」或「完全访问」，默认按需审批。按需审批时，Codex、DSH 在对话目录以外改文件或运行超出沙盒的命令前会询问，读取本机文件按它们自己的沙盒规则，通常不问；Pi 运行命令、改文件、读对话目录以外的文件前都会询问。Codex 的实时网页搜索只在完全访问下开启。完全访问允许读写本机文件、运行命令和联网，无需逐次审批；补充信息的提问仍保留。切换会停止当前运行，下次发送消息恢复同一会话并应用新权限。Codex 新建和恢复线程均设置 `danger-full-access` / `never`（[官方 app-server 协议](https://learn.chatgpt.com/docs/app-server)）；Pi 关闭 Emaki 的 shell/文件修改和越界读取确认。外部 MCP 客户端的权限由其自身管理。

关闭面板不停止对话；重新打开可恢复。停止按钮中断当前 agent，之后可继续同一对话。关闭实验开关会结束助手进程、禁用 MCP 并保留会话与配置。已启动的 Emaki 后台任务仍在「后台任务」中管理。

对话、发送时的页面地址和图片选择、查询结果（含文件路径和文件夹名、角色、标签、分级）及按需读取的图片会发送给所选模型服务。费用按该服务计费；联网搜索、看图及子 agent 能力由所选 Agent 应用提供，可按任务需要选择模型。

查出处时，助手可能用反向搜图，把图片上传到 Yandex、SauceNAO 等第三方搜图网站。随包技能要求：上传前用 `ask_user` 列出图片和网站，得到同意再传，用户在本次对话里明确要求以图搜图时除外；完全访问等权限不算同意；照片、截图和分级为 questionable、explicit 的图片，用户没有点名就不提议上传；只上传去掉 EXIF/GPS 等元数据的查询副本（`yandex-search.py` 有 Pillow 时还会重新编码到最长边 1280 像素，没有时只去元数据、尺寸不变）。系统指令还要求助手不用 shell、脚本或 HTTP 移动、改名、删除或改写图库文件，移动和移到回收站由用户在页面上操作。这些都是对模型的指令，不是程序层面的拦截：完全访问模式下命令不再逐次审批，按需审批时也只能从审批内容判断一条命令是否在上传图片。

Pi 可以读取本机 `PI_CODING_AGENT_DIR`（默认 `~/.pi/agent`）的模型及 API Key 配置；暂不复用 OAuth 登录，避免复制刷新令牌造成多个进程相互失效。也可以使用服务进程已有的供应商环境变量。Emaki 不枚举或导入该目录下的历史会话。

DSH 使用每个 Emaki 对话目录内的独立 `dsh-home` 和 ACP profile；只引用本机 DSH 的凭证文件，不复制可刷新的登录令牌，不导入其他会话。模型配置复用桌面 profile 的模型条目。`emaki-library` 与 `taste-profile` 仍使用同一份 canonical 技能，复制到当前会话的 `.agents/skills`。恢复时通过 DSH 权限服务应用 Emaki 当前的按需审批或完全访问设置。停止会取消当前工作并关闭本会话的进程；随后可以恢复同一原生会话。

DSH 启动时优先保留进程环境和原 DSH home `.env` 中的代理配置；未配置时沿用 Emaki 检测到的出网代理（包括 Windows 系统代理），只传给本次子进程。localhost MCP 保持直连，终端子进程也获得 loopback 绕过列表。代理设置变更在下次连接 DSH 时生效。网络代理不代替网站登录、验证码或访问权限。

当前 DSH ACP 提交完整思考、回复和工具生命周期后才发送语义更新，因此气泡不会逐 token 显示这部分内容。图片/表格卡片和用户选择使用 Emaki 的 `present_result` / `ask_user` 工具；DSH 专有 UI 卡片和 elicitation 不在此适配器中呈现。

## 给外部 Agent 配 MCP

开启实验功能，在设置中点「显示连接配置」，将生成的 Streamable HTTP 配置交给支持 MCP 的客户端。不同客户端的配置字段可能不同；共同需要 URL 和 `Authorization: Bearer …`。没有单独的 MCP 端口。开发模式使用后端端口（默认 5174）；生产模式使用应用实际端口。

| 工具 | 能力 |
| --- | --- |
| `import_images` | 将本地下载图片复制入库，返回图片 ID；精确查重、避免重名覆盖，支持撤销新增副本 |
| `describe_database` / `query_database` | 当前表结构、自由只读 SQL；关联、统计、抽样由 agent 自行组织 |
| `read_library` | 读取应用现有图库、角色、作品、任务、未识别等 API，保留页面口径 |
| `read_media` | 实际看图，也支持按像素裁剪局部 |
| `edit_source` | 保存已核实的来源 URL / 来源作者，人工确认优先于扫描；null 清空并保留，auto 恢复文件名解析，支持撤销 |
| `accept_suggestion` | 复用未识别页面的采纳建议流程，解析或创建角色、关联作品并返回撤销令牌 |
| `update_images` / `edit_character` | 调用原有业务接口修改图片和角色，保留原有校验、事件和可用的撤销能力 |
| `manage_job` | 查看、启动、取消应用已有后台任务 |
| `get_page_context` / `present_result` | 当前消息的页面选择快照、图片集合与表格；外部 MCP 无绑定网页会话时，前者返回 null，后者直接返回结果 |
| `ask_user` | 在 Emaki 对话中展示选项或输入框，保留提问时的图片范围；仅向绑定网页会话的 agent 提供 |

SQL 在独立子进程中以 SQLite 只读方式执行：单语句、5 秒时限、最多 5,000 行和约 1 MB 结果，超限标记 `truncated`。支持参数绑定；不暴露任意 SQL 写入。修改工具使用 `operationId` 去重；中断后结果不确定的操作要求先查询实际状态，不自动重放。

## 实现与扩展

- 后端适配器统一模型目录、发送、取消、交互响应与流事件。Codex 使用 app-server，Pi 使用官方 RPC，DSH 使用 ACP；新增后端不需要改图库工具。Claude Code 尚未实现。
- 服务端维护 Emaki 自己的会话索引，只接受索引中的 ID。原生会话 ID 不从浏览器接收、不向浏览器暴露。
- 设置、密钥、会话索引和操作记录位于 `EMAKI_DATA_DIR/assistant`；不进入图库 SQL 数据库，也不进入 Git。凭证文件应按本机账户权限保护。Pi 和 DSH 的原生会话也在其中；Codex 的原生线程在 `CODEX_HOME`。
- MCP 和网页复用业务接口；统一短 skill 位于 `apps/server/assets/assistant/emaki-library/SKILL.md`。Codex 通过项目 skill 目录加载，Pi 显式加载同一文件，不维护两份 SOP。
- 按需审批模式下，Codex 和 DSH 的权限请求以及 Pi 的 shell/文件修改、会话目录以外的读取请求显示在对话里。界面是非模态面板，可以边看图库边与 agent 交互。

## 验证

`npm run typecheck`、`npm test`、`npm run build`。

助手测试覆盖默认关闭、会话归属、SQL 写入拒绝与超时、MCP 图片返回、业务修改去重、SSE 断开、停止与恢复、多问题响应和 MCP 确认。停止期间的新请求等待连接释放，旧连接的迟到事件不会影响后续任务；模型目录变化后会更新失效的模型和思考强度选择。Pi 集成测试启动真实官方 harness，对接本地模拟模型 API，验证实际 MCP 往返，不访问用户图库或付费服务。

开发时的真实 Codex 验证应使用独立测试库，确认模型调用、网页确认、结果卡片与恢复行为；不能仅凭模型列表读取成功认定接入完成。

DSH 回归覆盖 ACP 会话归属、MCP 凭证、逐模型配置、无生成超时、语义消息与工具成功/失败、权限映射、取消与恢复，以及 Windows Electron carrier 定位。2026-10-20 在本机桌面壳 `2.0.18-beta.1` / 内置 `@deepseek-ai/dsh 0.2.1-rc.2` 上，使用隔离测试库验证了真实推理、查询、表格、看图、用户回答、越界文件审批、完全访问、停止与同会话恢复；没有修改实际图库。

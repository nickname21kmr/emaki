# AI 助手（实验）

设置 → **AI 助手 · 实验**，默认关闭。此功能独立于本机 tagger 和实验性的 Qwen 图片分类，不下载或部署推理模型。

## 使用

1. 打开开关，检测本机后端。检测只检查安装、认证状态和模型列表，不发起推理。
2. 在设置页选择后端：
   - **Codex**：使用已有 Codex 安装和登录。自动检查 PATH 及 Windows Codex 桌面安装位置；也可指定可执行文件的绝对路径。
   - **Pi**：随 Emaki 安装 `@earendil-works/pi-coding-agent`，填写模型 API 地址、协议、模型 ID 和密钥。支持 Chat Completions、Responses、Anthropic Messages。自定义模型的视觉和思考能力由配置声明；已有 Pi 模型的能力使用其模型目录。
3. 点右下角气泡，新建对话。气泡和面板标题栏均可拖动，位置记在本机浏览器；缩放窗口或展开面板时会保持在可见范围。模型和思考强度在输入框下方选择；后端在设置页切换。
4. 可以选中图库图片、打开一张图片，或直接提问。每条消息记录当时的页面和图片选择，图片由 agent 按需通过 MCP 读取。
5. 助手可返回图片卡片和表格。勾选卡片图片会更新输入框下方的上下文，再输入任意后续指令发送；“使用页面选择”可切回图库的选择。业务接口返回撤销令牌的修改可直接撤销。令牌遵循应用原有生命周期，重启后可能失效。

任务中断、出错或手动停止后，可点击“继续处理”或“重试并继续”。恢复沿用原请求的图片范围、会话历史与操作记录，助手先核对已完成部分，再继续剩余工作；也可直接输入新指令。短暂网络断线会自动重连，旁边提供“立即重连”入口。

连续工具记录默认折叠，展开后可查看详情和撤销；图片、表格结果卡片保持可见。未识别列表刷新成功后会清理已移出列表的选择，输入框上下文同步更新，已发送消息保留当时的选择快照。

设置 → AI 助手 → 操作权限可选择「按需审批」或「完全访问」，默认按需审批。完全访问允许读写本机文件、运行命令和联网，无需逐次审批；补充信息的提问仍保留。切换会停止当前运行，下次发送消息恢复同一会话并应用新权限。Codex 新建和恢复线程均设置 `danger-full-access` / `never`（[官方 app-server 协议](https://learn.chatgpt.com/docs/app-server)）；Pi 关闭 Emaki 的 shell/文件修改确认。外部 MCP 客户端的权限由其自身管理。

关闭面板不停止对话；重新打开可恢复。停止按钮中断当前 agent，之后可继续同一对话。关闭实验开关会结束助手进程、禁用 MCP 并保留会话与配置。已启动的 Emaki 后台任务仍在「后台任务」中管理。

对话、查询结果及按需读取的图片会发送给所选模型服务。费用按该服务计费；联网搜索、看图及子 agent 能力由所选后端提供，可按任务需要选择模型。

Pi 可以读取本机 `PI_CODING_AGENT_DIR`（默认 `~/.pi/agent`）的模型及 API Key 配置；暂不复用 OAuth 登录，避免复制刷新令牌造成多个进程相互失效。也可以使用服务进程已有的供应商环境变量。Emaki 不枚举或导入该目录下的历史会话。

## 给外部 Agent 配 MCP

开启实验功能，在设置中点「显示连接配置」，将生成的 Streamable HTTP 配置交给支持 MCP 的客户端。不同客户端的配置字段可能不同；共同需要 URL 和 `Authorization: Bearer …`。没有单独的 MCP 端口。开发模式使用后端端口（默认 5174）；生产模式使用应用实际端口。

| 工具 | 能力 |
| --- | --- |
| `describe_database` / `query_database` | 当前表结构、自由只读 SQL；关联、统计、抽样由 agent 自行组织 |
| `read_library` | 读取应用现有图库、角色、作品、任务、未识别等 API，保留页面口径 |
| `read_media` | 实际看图，也支持按像素裁剪局部 |
| `edit_source` | 保存已核实的来源 URL / 来源作者，人工确认优先于扫描；null 清空并保留，auto 恢复文件名解析，支持撤销 |
| `accept_suggestion` | 复用未识别页面的采纳建议流程，解析或创建角色、关联作品并返回撤销令牌 |
| `update_images` / `edit_character` | 调用原有业务接口修改图片和角色，保留原有校验、事件和可用的撤销能力 |
| `manage_job` | 查看、启动、取消应用已有后台任务 |
| `get_page_context` / `present_result` | 当前消息的页面选择快照、图片集合与表格；外部 MCP 无绑定网页会话时，前者返回 null，后者直接返回结果 |

SQL 在独立子进程中以 SQLite 只读方式执行：单语句、5 秒时限、最多 5,000 行和约 1 MB 结果，超限标记 `truncated`。支持参数绑定；不暴露任意 SQL 写入。修改工具使用 `operationId` 去重；中断后结果不确定的操作要求先查询实际状态，不自动重放。

## 实现与扩展

- 后端适配器统一模型目录、发送、取消、交互响应与流事件。Codex 使用 app-server，Pi 使用官方 RPC；新增后端不需要改图库工具。Claude Code 尚未实现。
- 服务端维护 Emaki 自己的会话索引，只接受索引中的 ID。原生会话 ID 不从浏览器接收、不向浏览器暴露。
- 设置、密钥、会话索引和操作记录位于 `EMAKI_DATA_DIR/assistant`；不进入图库 SQL 数据库，也不进入 Git。凭证文件应按本机账户权限保护。
- MCP 和网页复用业务接口；统一短 skill 位于 `apps/server/assets/assistant/emaki-library/SKILL.md`。Codex 通过项目 skill 目录加载，Pi 显式加载同一文件，不维护两份 SOP。
- 按需审批模式下，Codex 的权限请求以及 Pi 的 shell/文件修改请求显示在对话里。界面是非模态面板，可以边看图库边与 agent 交互。

## 验证

`npm run typecheck`、`npm test`、`npm run build`。

助手测试覆盖默认关闭、会话归属、SQL 写入拒绝与超时、MCP 图片返回、业务修改去重、SSE 断开、停止与恢复、多问题响应和 MCP 确认。Pi 集成测试启动真实官方 harness，对接本地模拟模型 API，验证实际 MCP 往返，不访问用户图库或付费服务。

开发时的真实 Codex 验证应使用独立测试库，确认模型调用、网页确认、结果卡片与恢复行为；不能仅凭模型列表读取成功认定接入完成。
